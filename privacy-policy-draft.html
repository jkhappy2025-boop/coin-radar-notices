Coin Radar 개인정보처리방침

Coin Radar 운영자는 앱의 시장 분석 정보 제공, 안정적인 서비스 운영 및 광고 제공 과정에서 아래와 같이 정보를 처리합니다. 개인정보 관련 문의는 jkhappy2025@gmail.com으로 보내실 수 있습니다.

1. 앱 기능과 기기 내 저장

Coin Radar는 서버에서 생성한 코인 시장 분석 결과, 그래프 및 로고를 내려받아 표시합니다. 회원가입이나 거래소 계정 연결을 요구하지 않으며, 거래소 API 키·비밀번호·주문·지갑 개인키를 수집하지 않습니다. 관심종목, 사용자가 기기에 기록한 보유종목 정보, 언어 및 화면 설정, 분석 결과와 그래프 캐시는 기기에 저장됩니다. 앱은 이 관심·보유 목록을 분석 서버에 업로드하지 않습니다. 사용자가 화면 공유 기능으로 내보내는 자료는 사용자가 선택한 앱과 수신자에게 전달됩니다.

2. 서비스 접속 정보

서버와 네트워크 제공자는 응답 전달과 보안을 위해 IP 주소 등 통신 정보를 처리합니다. Coin Radar 분석 게이트웨이는 요청 경로의 종류, 요청 수, 전송량, 응답 시간, 오류 및 동시 처리 수를 집계합니다. 이용량 추정을 위해 IP 주소를 매일 바뀌는 비밀값으로 변환한 식별값을 해당 날짜 동안 보관합니다. 이 운영 통계 파일에는 원본 IP 주소, 조회 코인명, URL 쿼리, 앱 계정 또는 광고 식별자를 저장하지 않습니다. 원본 IP는 요청 처리 및 일시적인 요청 제한에 사용됩니다.

분 단위 통계는 24시간, 시간 단위 통계는 30일, 일 단위 집계 통계는 90일 보관한 후 정리합니다. 이러한 정보는 서비스 안정성 확인, 이용량 분석, 과도한 요청 방지 및 장애 대응에 사용합니다.

3. Google 광고 및 동의 관리

앱은 Google Mobile Ads SDK와 User Messaging Platform(UMP)을 사용합니다. 정식 배포 앱에는 Google 광고가 표시되며, 테스트 환경에서는 테스트 광고가 표시될 수 있습니다. 광고 제공 과정에서 아래에 설명된 정보가 처리될 수 있습니다. Google SDK는 광고 제공·측정, 분석 및 부정행위 방지를 위해 IP 주소(대략적인 위치 추정에 사용될 수 있음), 광고·앱 상호작용, 진단·성능 정보, 광고 ID 및 앱 세트 ID 등 기기 식별자를 수집하거나 공유할 수 있습니다. 처리 범위는 기기 설정, 동의 상태와 SDK 동작에 따라 달라집니다. 앱은 기기의 대략적 위치, 정확한 위치 또는 백그라운드 위치 권한을 요청하지 않습니다. 다만 Google 광고 서비스와 네트워크 제공자는 IP 주소를 이용하여 대략적인 지역을 추정할 수 있습니다.

적용되는 지역에서는 Google 동의 화면과 앱의 ‘개인정보 및 광고 설정’에서 제공되는 선택 기능을 사용할 수 있습니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다. Google이 처리하는 정보의 보관과 삭제는 Google 정책을 따릅니다. Google 개인정보처리방침 · Google 파트너 앱의 정보 사용

4. 서비스 제공업체와 외부 링크

앱 분석 API의 연결·보안·전송에는 Cloudflare를, 서버 호스팅에는 Amazon Web Services(AWS)를 이용합니다. 이 업체들은 서비스 제공과 보안을 위해 통신 정보를 처리할 수 있으며, 제공업체의 글로벌 인프라에 따라 국외에서 처리될 수 있습니다. Coin Radar 운영자는 개인 정보를 판매하지 않습니다. 각 제공업체의 정보 처리에는 해당 업체의 정책도 적용됩니다.

Cloudflare 개인정보처리방침 · AWS 개인정보처리방침

코인 세부 화면의 외부 링크나 광고를 선택하면 외부 서비스로 이동할 수 있습니다. 해당 서비스의 계정·거래·정보 처리는 그 서비스의 정책에 따릅니다. Coin Radar 자체는 거래 주문을 실행하거나 자산을 보관하지 않습니다.

5. 차트 및 공지사항 연결

코인 상세 화면의 일봉 차트는 선택한 거래쌍과 일봉 조회 조건을 Binance의 공개 시장 데이터 서비스에 직접 요청합니다. Binance는 연결에 필요한 IP 주소와 요청 시각, 요청 내용 등 통신 정보를 처리할 수 있습니다. 상세 화면을 열어 둔 동안 당일 일봉을 주기적으로 갱신할 수 있습니다. 거래소 계정 로그인, API 키 또는 거래 주문은 이 요청에 포함되지 않습니다.

공지사항은 GitHub에서 공개 공지 파일을 직접 내려받습니다. 앱을 사용하지 않는 동안에도 기기의 백그라운드 작업이 공지를 확인할 수 있으며, 기기 설정에 따라 새 공지 알림이 표시될 수 있습니다. GitHub는 IP 주소와 요청 시각 등 연결 정보를 처리할 수 있습니다. 각 제공자의 이용·보관 및 삭제는 해당 제공자의 정책과 실제 운영 방식에 따릅니다.

6. 삭제 및 문의

기기에 저장된 정보는 앱 내 목록 삭제 기능, Android의 앱 저장공간 삭제 또는 앱 제거로 삭제할 수 있습니다. 앱 계정은 생성하지 않습니다. 서버 운영 통계의 식별값은 매일 교체되어 장기간의 특정 사용자 기록과 연결하지 않으며, 개인별 기록을 찾아 제공하거나 삭제하는 데 제한이 있을 수 있습니다. 정보 처리에 관한 확인·정정·삭제 요청은 위 문의 이메일로 보내주세요. 문의 시 보낸 이메일 주소와 문의 내용은 답변을 위해 처리하며, 문의가 종결되어 보관 필요가 없어지면 삭제합니다. 법령상 별도 보관 의무가 있는 경우 해당 기간을 따릅니다.

7. 보안과 대상 이용자

앱과 분석 API 간 통신은 HTTPS를 사용합니다. 서버 운영 통계 관리 화면은 인증된 운영자만 접근할 수 있습니다. Google 광고 SDK의 데이터 전송도 TLS를 사용합니다. 앱은 성인 이용자를 대상으로 하며 어린이를 대상으로 설계하지 않았습니다.

8. 변경 안내

기능이나 데이터 처리 방식이 변경되면 이 페이지의 시행일과 내용을 갱신합니다. 중요한 변경은 적용되는 법령과 플랫폼 정책에 따라 안내합니다.
